# PSM I Тренажёр

Приложение для подготовки к экзамену Professional Scrum Master I (PSM I): 250 вопросов на английском, перевод на русском и объяснения на русском и English. Это обычный сайт из статичных файлов (PWA), отдельный сервер не нужен.

## Что умеет
- Тренировка: выбор вопросов (все, новые, ошибки, отмеченные), количество, порядок, перемешивание вариантов.
- Язык вопросов: English или English + русский по кнопке «Показать по-русски».
- Объяснения на русском и English: нет, при ошибке или после каждого ответа.
- Пробный экзамен: 80 вопросов, 60 минут, проходной балл 85%, разбор в конце.
- Прогресс сохраняется на устройстве. Есть сохранение в файл и загрузка из файла, чтобы переносить между устройствами.
- После первой загрузки работает без интернета.

## Как открыть на телефоне и планшете (один раз выложить на хостинг)
Нужна ссылка вида https://..., потому что установка на телефон и работа без интернета требуют адреса сайта, а не файла.

### Вариант 1: GitHub Pages (бесплатно)
1. Создай аккаунт на github.com и новый репозиторий (Public), например `psm1-trainer`.
2. Нажми «Add file», затем «Upload files» и загрузи все файлы и папки из этой папки (index.html, app.js, styles.css, sw.js, manifest.webmanifest, data, icons, .nojekyll).
3. Открой Settings, затем Pages. В Source выбери ветку `main` и папку `/ (root)`, нажми Save.
4. Через минуту сайт будет по адресу `https://ТВОЁ_ИМЯ.github.io/psm1-trainer/`.

### Вариант 2: Netlify Drop (без аккаунта GitHub)
Открой app.netlify.com/drop и перетащи в окно всю эту папку. Netlify выдаст ссылку.

### Установка
- iPhone и iPad (Safari): «Поделиться», затем «На экран Домой».
- Android (Chrome): меню ⋮, затем «Установить приложение».
- Компьютер (Chrome, Edge): значок установки в адресной строке.

## Запуск на компьютере для проверки
```
cd psm1-app
python3 -m http.server 8000
```
Затем открой http://localhost:8000. Простое открытие index.html двойным кликом тоже работает, но без установки и без работы офлайн.

## Как обновлять
- Тексты вопросов, переводы и объяснения лежат в `data/questions.js`.
- После любых изменений файлов поменяй номер версии `CACHE` в `sw.js` (например `psm1-v2`), иначе телефон будет показывать старую версию из кэша.

## Источник и оговорки
Вопросы: github.com/Ditectrev/Scrum-Master-I-PSM-I-Practice-Tests-Exams-Questions-Answers. Правильные ответы в нём написало сообщество, поэтому бывают ошибки и устаревшие формулировки. Объяснения сверены со Scrum Guide 2020; значком ⚠️ отмечены места, где ключ расходится с Guide или относится к практике вне Scrum.
